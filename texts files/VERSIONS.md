--- этап 0 - подготовка [в процессе] --- 

0.0.0.01 - стартовое окно [готово]
- запуск окна с пустой сценой
- закрытие на esc
0.0.1.01 - скелет под консольку [готово]
- по клавише ~ вызывается простое окно консольки
- возможность ввода-вывода базовых команд (hello world для старта)
- возможность выхода из консоли на команду "/close"
0.0.2.01 - простейшая генерация игрового поля [готово]
- генерация игрового поля 1024х1024 (пока хватит) с различными биомами:
	- глубокая вода, вода, мелководье, пляж, поле, редколесье, лес, густой лес, холм, гора, снежные вершины)
- присвоение клеткам состояний
	- возможность и скорость ходьбы, плодородность, возможность строительства
- по комманде "/region_info" показывается информация о клетке
0.0.3.01 - камера [готово]
- возможность перемещать камеру на wasd
- zoom по колесику мыши
- перемещение камеры по нажатию на ЛКМ
0.0.2.02 - автолоад состояний [готово]
- перенос функции присвоения состояний в autoload
0.0.0.02 - индикаторы [в процессе]

--- этап 1 - базовые жители [не начато] ---

0.1.4.01 — структура Villager (только данные, без отрисовки) [не начато]
- Класс с полями: health, speed, hunger, name
- Создание массива villagers
0.1.4.02 — отрисовка жителей [не начато] 
- Простая текстурка (кружок или спрайт)
- Отображение всех жителей из массива на карте
0.1.4.03 — базовое движение [не начато]
- Жители случайно бродят
0.1.1.02 - спавн жителей через консоль [не начато]
- по комманде "/spawn: villager (число)" в центре карты появляется (число) новых жителей
- по комманде "/kill villager (число)" случайно умирают (число) жителей
- при нажатии на жителя в консольке отображаются его параметры
0.1.5.01 - UI [не начато]
- создание UI области отображения ресурсов (как в римворлд)
0.1.6.01 - еда [не начато]
- при старте игры ресурс "еда" = 10
- каждый житель каждую 1 секунду теряет 10 сытости
- при сытости < 30 житель потребляет 1 "еда" и восстанавливает 50 сатости
- если сытость = 0, то житель умирает
- каждое изменение числа ресурса оно меняется в UI области
0.1.1.03 - возможность добавлять еду в консольке [не начато] 
- по команде "/add food (число)" добавляется (число) еды
- по команде "/del food (число)" убирается (число) еды



примечание к версиям (z):
0 - скелет
1 - консолька
2 - генерация
3 - система
4 - жители
5 - UI
